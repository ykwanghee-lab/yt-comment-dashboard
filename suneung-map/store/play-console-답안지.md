# Play Console 입력 답안지 (수능시험장 찾기)

폰에서 하려면 크롬으로 play.google.com/console 을 열고, 오른쪽 위 점 세 개 → "데스크톱 사이트"를 켜면 편합니다.
앱을 만든 뒤 왼쪽 메뉴 "앱 콘텐츠"(또는 대시보드의 "앱 설정") 항목을 위에서부터 채웁니다.

## 5. 비공개 테스트 (집에서, 앱 파일 업로드 후)
- 테스트 및 출시 → 비공개 테스트 → 트랙 만들기 → 테스터: "이메일 목록" 만들고 테스터 Gmail 12개 이상 입력
- 국가: 대한민국
- 앱 번들 업로드: GitHub Actions 에서 받은 `app-release.aab`
- 테스터에게 "웹에서 참여" 링크를 카톡으로 보내고, 각자 링크 열어 "테스터 되기" + 플레이스토어에서 설치까지 해야 1명으로 집계됨
- 12명 이상이 14일 연속 유지되어야 프로덕션 신청 가능
