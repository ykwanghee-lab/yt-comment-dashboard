# 시험장 데이터 파이프라인

`sites.csv` (사람이 편집) → `build_sites.py` → `../web/data/sites.json` (앱이 읽음)

## 실제 명단 수집 절차 (11월 초, 시·도교육청 발표 직후)
1. 17개 시·도교육청 보도자료/공지에서 "수능 시험지구별 시험장 명단"을 내려받는다 (PDF/HWP).
   - 교육청마다 형식이 다르므로 표를 복사해 `sites.csv` 형식으로 정리한다.
   - 시험지구 번호(수험번호 앞 2자리)와 시험장 번호(3~4자리)를 명단 표기 그대로 적는다.
2. 주소는 나이스 학교기본정보 또는 학교알리미 기준 도로명 주소를 쓴다.
3. 좌표가 비어 있으면 `KAKAO_REST_KEY=... python3 build_sites.py --geocode` 로 채운다.
4. `python3 build_sites.py --status official --version 2027-1` 실행 후 `web/data/sites.json` 을 배포한다.
5. 앱은 다음 실행 시 자동으로 새 데이터를 받는다(네트워크 우선, 오프라인 시 캐시).

## 검증
- id(지구2+시험장2)는 전국 고유. 중복이면 빌드가 실패한다.
- 좌표는 한국 범위 밖이면 실패한다.
- 교육청 명단 발표 후에도 "수험표로 최종 확인" 문구는 유지한다.
