# PC(Windows)에서 Claude Code가 할 일: 수능 시험장 실제 명단 수집

클라우드 세션은 교육청·위키 사이트 접속이 막혀 있어서, 인터넷이 되는 PC에서 이 작업을 한다.
**정확성이 전부다.** 잘못된 시험장은 수험생에게 실제 피해를 준다. 찾지 못한 지역은 비워 두고 보고하며, 추측으로 채우지 않는다.

## 목표
1. 지금: 작년(2026학년도, 2025-11-13 시행) 시험장 명단으로 `sites.csv` 를 채우고 `provisional` 로 배포한다.
   앱은 이 모드에서 수험번호 조회를 잠그고, 지역·학교 찾기와 길찾기만 연다.
2. 11월 초: 17개 시·도교육청이 2027학년도 명단을 모두 발표하면 교체하고 `official` 로 배포한다. 이때 수험번호 조회가 열린다.

|---|---|---|---|

## 1. 명단 찾기 (시·도별)
- 1순위: 각 시·도교육청의 "대학수학능력시험 시행 세부계획" 보도자료와 첨부(HWP/PDF). 2025년 10월 말~11월 초 게시분.
- 교차 확인: 나무위키 "대학수학능력시험/시험장" 문서. 학년도 표기가 없으면 교육청 자료를 우선한다.
- 시험지구 번호(수험번호 앞 2자리)와 시험장 번호(3~4자리)는 **자료에 적힌 그대로** 쓴다. 자료에 번호가 없으면 비워 두고 `note` 에 "번호없음" 을 적는다. 번호 없는 행은 빌드 전에 사용자에게 보고한다.
- 17개 시·도 각각 찾은 시험장 수를 표로 남긴다. 합계가 1,310과 크게 다르면 빠진 곳을 다시 찾는다.

## 2. 주소 채우기
- 학교 도로명 주소는 NEIS 교육정보 개방포털 학교기본정보 API 로 찾는다.
  `https://open.neis.go.kr/hub/schoolInfo?Type=json&SCHUL_NM=<학교명>&ATPT_OFCDC_SC_CODE=<교육청코드>` 의 `ORG_RDNMA`
  (키 없이도 소량 조회가 된다. 많이 막히면 사용자에게 무료 인증키 발급을 부탁한다.)
- 같은 이름 학교가 여러 곳이면 시험지구 지역과 맞는 곳을 고른다. 애매하면 `note` 에 "동명학교확인" 을 적는다.

## 3. CSV 작성 규칙
- 파일: `suneung-map/data/sites.csv`. 맨 위 주석과 헤더 형식을 그대로 유지하고, 샘플 7행은 지운다.
- `region_code` 는 파일 주석의 시·도 코드표를 따른다.
- `note` 는 비워 두거나 위의 표시만 쓴다. "샘플" 은 쓰지 않는다.
- `lat`, `lng` 는 비워 둔다 (4단계에서 채운다).

## 4. 좌표 채우기와 빌드
```powershell
Set-Location "$env:USERPROFILE\work\yt-comment-dashboard\suneung-map\data"
python build_sites.py --geocode --status provisional --basis-year 2026학년도
```
- 카카오 REST 키가 있으면 `$env:KAKAO_REST_KEY` 로 넘기면 빠르다. 없으면 OpenStreetMap으로 초당 1건씩 처리된다 (1,300건 약 25분).
- 결과는 `geocode_cache.json` 에 저장되어 다시 돌려도 이미 찾은 주소는 건너뛴다. 이 파일도 커밋한다.
- 지오코딩 실패 행은 오류로 나온다. 주소를 고쳐 다시 돌린다.

## 5. 검증 (모두 통과해야 배포)
- [ ] 시·도별 시험장 수 표를 사용자에게 보여 주고 합계 확인
- [ ] 무작위 10곳: 좌표를 지도에서 열어 실제 그 학교 위치인지 확인
- [ ] 같은 좌표에 서로 다른 학교가 겹친 곳이 없는지 확인
- [ ] 로컬 실행: `cd ..\web; python -m http.server 8765` 후 브라우저에서 찾기 화면의 시·도·지구 목록과 학교 수 확인, 홈 화면의 수험번호 칸이 잠겨 있는지 확인

## 6. 배포
- `sites.csv`, `geocode_cache.json`, `web/data/sites.json`, `web/data/sites.js` 를 커밋하고 `main` 에 푸시한다. 1~2분 뒤 앱에 반영된다.
- 저장소 루트의 유튜브 대시보드 파일은 건드리지 않는다.

## 7. 11월 초 2027학년도 교체
- 17개 시·도가 모두 발표한 뒤에만 `official` 로 바꾼다. 일부만 발표된 상태에서는 `provisional` 을 유지한다
  (작년 번호와 올해 번호가 섞이면 수험번호 조회가 다른 학교를 보여 줄 수 있다).

- 5단계 검증을 다시 한다. 특히 수험번호 앞 4자리 몇 개를 실제 명단과 대조한다.
