# 수능시험장 찾기 (suneung-map)

수험번호 앞 4자리 또는 지역·학교 이름으로 수능 시험장을 찾고, 네이버지도·카카오맵·티맵·기본 지도앱으로 바로 길찾기를 시작하는 앱입니다.
웹앱(PWA)을 먼저 배포하고, 같은 코드를 TWA로 포장해 Google Play 에 올립니다.

- 2027학년도 수능: 2026-11-19(목), 예비소집(수험표 교부) 11-18(수), 입실 완료 08:10
- 수험번호 8자리 = 시험지구(2) + 시험장(2) + 시험실(2) + 좌석(2). 앱은 앞 4자리만 받고, 기기 밖으로 보내지 않습니다.

## 폴더
| 경로 | 내용 |
|---|---|
| `web/` | PWA 본체 (의존성 없음: `index.html`, `app.js`, `style.css`, `sw.js`, `manifest.webmanifest`, `icons/`, `data/sites.json`) |
| `data/` | 시험장 원본 CSV와 JSON 변환기 (`build_sites.py`) |
| `android/` | Bubblewrap(TWA) 설정과 Play 출시 체크리스트 |

## 로컬 실행
```bash
cd web && python3 -m http.server 8765
# 브라우저에서 http://localhost:8765/index.html  (샘플 수험번호: 0101, 0201, 2101, 3101)
```

## 기능
- 홈: D-day, 수험번호 앞 4자리 입력(4자리 입력 즉시 조회), 내 시험장 카드
- 찾기: 시·도 → 시험지구 → 학교 검색, 현재 위치 기준 가까운 시험장
- 상세: 지도 미리보기, 자동차/대중교통/도보 전환, 네이버지도·카카오맵·티맵·기본지도 딥링크(미설치 시 스토어), 출발 시각 계산, 캘린더(.ics) 추가, 가족에게 공유, 내 시험장 저장
- 체크리스트: 예비소집일/시험 당일 준비물, 반입 금지 물품 (기기 내 저장)
- 오프라인: 앱 셸 캐시, 데이터는 네트워크 우선 + 캐시 폴백

## 데이터 상태
`web/data/sites.json` 의 `status` 가 `sample` 이면 앱 상단에 샘플 안내가 뜹니다. 교육청 명단 반영 후 `official` 로 바꿉니다. 절차는 `data/README.md`.

## 배포
1. GitHub Pages 로 `web/` 를 HTTPS 배포 (저장소 설정 → Pages). 배포 URL 을 `android/twa-manifest.json` 에 반영
2. `android/README.md` 대로 AAB 빌드 → Play Console 비공개 테스트 → 프로덕션
